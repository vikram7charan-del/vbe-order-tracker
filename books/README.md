# नई पुस्तक कैसे जोड़ें — 4 चरण

> कोड छूने की ज़रूरत नहीं। एक JSON फ़ाइल डालिए, बस।

### 1. किताब का पाठ तैयार कीजिए

दो रास्ते हैं —

**(क) अध्याय-दर-अध्याय JSON** *(जैसा कम्पाउंड इफ़ेक्ट में किया)*
```
book/<किताब>/data/ch01.json
book/<किताब>/data/ch02.json
book/<किताब>/images/ch01_fig01.svg
```

**(ख) सीधा हिंदी में लिखकर**
`nayi-pustak/adhyayan.md` में — तरीक़ा `nayi-pustak/README.md` में।

### 2. एक आदेश चलाइए

```
node scripts/book-json-banao.js <किताब>      ← रास्ता (क)
node scripts/adhyayan-banao.js               ← रास्ता (ख)
```

### 3. जाँच लीजिए

```
node scripts/validate-book.mjs
```
गड़बड़ हो तो साफ़ हिंदी में बता देगा — खाली पाठ, टूटा अध्याय, गुम चित्र,
दोहरी पहचान, पीछे जाता पृष्ठ-अंक।

### 4. बस

`adhyayan.html` खोलिए — किताब पुस्तकालय में आ चुकी है।
लिंक: `adhyayan.html#<पहचान>`

---

## यहाँ क्या-क्या बनता है

| फ़ाइल | क्या |
|---|---|
| `books/index.json` | सारी किताबों की सूची — **यही सच है** |
| `books/<id>.json` | एक किताब — यही सच है |
| `data/adhyayan-<id>.js` | वही किताब, script-tag रूप — **बिना server** भी खुल जाए |
| `data/adhyayan-registry.js` | वही सूची, script-tag रूप |

ऐप पहले `.json` माँगता है; न मिले (फ़ाइल सीधे फ़ोन में खोली हो) तो `.js` से काम चला लेता है।
दोनों एक ही आदेश से बनते हैं — हाथ से किसी को मत बदलिए, `validate-book` पकड़ लेगा।

## किताब का ढाँचा

```json
{
  "id": "compound-effect",
  "meta": { "title": "…", "author": "…", "accent": "#C89545", "words": 5628, "readMins": 31 },
  "chapters": [{
    "id": "ch1", "number": 1, "title": "…", "sourcePages": "1-17",
    "blocks": [
      { "type": "page",    "n": 1 },
      { "type": "p",       "id": "1czssmk", "text": "…", "note": "स्रोत की टिप्पणी (वैकल्पिक)" },
      { "type": "h2",      "id": "…", "text": "बीच का शीर्षक" },
      { "type": "quote",   "id": "…", "text": "बॉक्स में छपा सूत्र-वाक्य" },
      { "type": "calc",    "id": "…", "text": "गणना का डिब्बा" },
      { "type": "figure",  "id": "…", "src": "book/…/fig01.svg", "label": "फ़िगर 1",
                           "n": 12, "caption": "…", "description": "चित्र में क्या है" },
      { "type": "actions", "id": "…", "heading": "कार्य क़दम",
                           "items": [{ "id": "…", "text": "…" }], "footer": "…" }
    ]
  }]
}
```

### `id` सबसे ज़रूरी है

हर हिस्से का `id` उसके **अपने पाठ** से बनता है (FNV हैश)। आपके निशान और नोट
इसी से जुड़े रहते हैं — इसलिए **किताब दोबारा चढ़ाने पर भी वे बचे रहते हैं**,
बशर्ते उस हिस्से का पाठ न बदला हो। इसीलिए `id` हाथ से मत लिखिए, आयातक को बनाने दीजिए।

### `category`
`"study"` वाली किताबें ही `adhyayan.html` में खुलती हैं।
ग्रंथ (हरिरस, देवियांण) की अपनी अलग व्यवस्था है — `data/registry.js` और `granth.html` —
यह सूची उन्हें छूती भी नहीं।
